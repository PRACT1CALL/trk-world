# TRK World — ONLINE

Браузерная 3D-игра с **общим городом**. Клиент сделан на WebGL, сервер — Node.js + WebSocket (`ws`). Игроки видят друг друга, ники, скины и дома с уровнями. Сохранились прогулки, WSUK, МҚТУ, Turan Mall, гиды, реальные погодные данные (когда API доступен), WASD/ЦФЫВ, бег и прыжок.

## Запуск на своём компьютере

1. Установить Node.js 20+.
2. Распаковать ZIP, открыть терминал **в папке проекта**, выполнить `npm install`, затем `npm start`.
3. Открыть в браузере `http://localhost:3000`.
4. Чтобы протестировать двух игроков, открыть этот адрес в двух **разных профилях браузера**. Выбрать разные ники. В одной сети можно подключиться с другого устройства, указав локальный IP компьютера вместо `localhost` (настроить файрвол при необходимости).

**Не открывать `public/index.html` из ZIP двойным щелчком** для совместной игры: это только офлайн-режим. Сервер должен быть запущен.

## Публикация на Render

1. Загрузить **всю папку проекта** в репозиторий GitHub (не только HTML).
2. На Render создать **Web Service** и выбрать репозиторий.
3. Node runtime, Build: `npm install`, Start: `npm start`, Health check: `/healthz` (или воспользоваться `render.yaml`).
4. Render выдаст HTTPS-ссылку. Отправить **одну и ту же ссылку** другу. Сайт сам подключится к WebSocket того же домена.

Приложение не требует отдельных API-ключей для мультиплеера. Подключение к Render или публикация через сервис требуют разрешения владельца аккаунта.

## Важно

- Прототип: нет паролей, реальной проверки личности или защиты ника как в полноценной игре. Ник закреплён за **случайным ключом устройства**, сохранённым в браузере. Не используйте настоящие имена и личные данные в никах.
- В бесплатном Render локальные файлы **не сохраняются гарантированно** после перезапуска/нового развертывания. Чтобы дома и прогресс сохранялись навсегда, нужен постоянный диск или база данных.
- Текущая версия рассчитана примерно на **40 игроков одновременно** в одном экземпляре сервера.
- Задания «пригласи друга», «подпишись», «сторис» в демо подтверждаются самим игроком; их выполнение автоматически не проверяется.
- Игровые координаты объектов и улиц остаются стилизованной моделью, не геоданными точного масштаба.

## Задание «Подпишись на авторов»

В списке заданий есть ссылки на оба Instagram-профиля. После подписки игрок нажимает «Я подписался на обоих» и однократно получает **+1 XP**. Проверка подписки отсутствует: кнопка работает по честному подтверждению игрока. Instagram-пароли или данные профиля не запрашиваются.
